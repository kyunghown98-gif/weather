# 🌤️ Weather App & Mini Games
"날씨를 확인하는 시간을 즐거움으로 바꾸다"

이 프로젝트는 단순한 날씨 정보 제공을 넘어, 사용자에게 시각적 즐거움과 상호작용 가능한 컨텐츠를 제공하는 React 기반 웹 애플리케이션입니다. **사이버펑크(Dark)**와 **미국 레트로(Light)**라는 극명한 대비를 이루는 두 가지 테마를 통해 독창적인 사용자 경험(UX)을 설계했습니다.

##🖼️ Preview


##✨ 주요 기능
-실시간 날씨 정보: OpenWeatherMap API를 연동한 현재 날씨 및 상세 데이터 제공

-다중 예보 시스템:

Swiper.js를 활용한 슬라이드 방식의 시간별 예보

최고/최저 온도 범위를 시각화한 주간 예보(5일)

-데이터 시각화: Recharts를 사용한 직관적인 기온 변화 그래프

-도시 관리: 검색 및 목록 저장 기능을 통한 다국적 날씨 확인

-엔터테인먼트 요소: 날씨 확인 대기 시간이나 무료함을 달래줄 4종 미니 게임 제공

-커스터마이징:

단위 전환 (°C / °F)

-컨셉 기반 테마: 사이버펑크(Dark) vs 미국 레트로(Light) 토글

-UI 디테일: React-fast-marquee를 활용한 실시간 시각 및 뉴스 스타일의 자동 스크롤 마퀴

## 기술 스택
- React
- React Redux
- Redux Toolkit
- Axios
- Swiper.js
- Recharts
- React-fast-marquee

## 🚀 차별화 포인트 (Key Points)
-독창적인 테마 시스템: 단순히 밝고 어두운 차이를 넘어, 사이버펑크와 레트로라는 명확한 컨셉 아트를 UI에 녹여내어 디자인 역량을 강조했습니다.

-컴포넌트 기반 아키텍처: 각 기능을 독립적인 컴포넌트로 분리하여 유지보수성을 높였으며, Redux Toolkit을 통해 상태 변화가 복잡한 날씨 데이터와 게임 로직을 효율적으로 관리했습니다.

-사용자 체류 시간 고려: 날씨 앱의 단조로움을 깨기 위해 4가지 종류의 미니 게임을 탑재하여 서비스의 재미 요소를 더했습니다.
